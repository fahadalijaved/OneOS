# Full-app closed controller packaging

Source preparation only. The ignored OneOS clone now has two scoped changes: its app/build.gradle.kts and full-edition manifest. The canonical Java sources and existing launch, root script, package lists, compatibility gates and security guards were not changed by this author. No Gradle, compiler, APK, native executable, installer or device workflow ran here.

The full manifest merges com.fahadali.oneos.core.root.RetainedRootHostService with exported=false, no intent filter, no permission grant and no directBootAware attribute. The accepted six Java sources belong only under app/src/full/java/com/fahadali/oneos/core/root; Root owns copying their exact current reviewed source after installer integration. This author did not copy them or activate a service.

The explicit local property oneos.retainedControllerFile selects an already-built artifact. Without it, Full emits RETAINED_CONTROLLER_SHA256="" and RETAINED_CONTROLLER_BYTES=0L and wires no controller asset task; ordinary Full and Probe do not require a native artifact. The service/setup path must fail closed if reached with these disabled pins. Merely defining the optional path does not publish a backend, create a protected host profile or start native work.

With the property, the full-only generated asset task admits only the existing596,312-byte native artifact SHA2561cacc47717468c6e91b791126ce011af25dab9bdbde50765ec0a013cea2b116b. Missing/nonregular/symlink input, zero/over2MiB content, wrong size/hash or failed readback refuses the selected task. It captures at most2MiB+1 bytes into an owned snapshot before hashing and writes only those verified bytes to build/generated/retained-controller/assets/root/oneos_retained_root_session. Readback is bounded too. The input is not selected from a moving build receipt and no binary is checked in. The source receipt is evidence of the admitted artifact, not a task input or runtime/source attestation.

Enabled full BuildConfig constants are RETAINED_CONTROLLER_SHA256:String and RETAINED_CONTROLLER_BYTES:long, matching the setup author's API. The generated asset directory is registered only for full variants. Probe receives no generated controller directory or pin fields, has no dependency on the asset task and additionally forbids the controller basename in its existing APK audit. No compression rule is added: AssetManager.open exposes uncompressed asset bytes, and the eventual APK/installer must verify their actual size/hash rather than infer them from a task marker.

The authored normal Gradle and manifest patches under compat/app-integration contain the exact clone deltas, with exact original working-file beforeimages retained in out/full-app-package-integration/history/before-packaging/. They preserve the baseline files' line endings and existing content outside the scoped additions/replacements. XML parsing confirms exactly one selected service declaration and its attributes; this is not an Android manifest merger or package build.

The root installer command, its SCRIPT_DATA temporary verified bootstrap, RootVerbs/RootScript changes and setup implementation belong to other authors. Root owns their integration, actual full APK source closure, SDK37 gating, merged manifest, Probe/full exclusion checks, package/asset byte readback, signing and eventual publication. Existing SHA pins and a packaged closed controller do not grant native/kernel, host authority, guest startup, PIN/biometric or device acceptance. The app broker remains closed/no-spawn on bind; protected profile/source association is separate.
