# Protected closed-root host link profile

Source-only implementation; no profile is created or written, and no Android or device action ran. HostRootLinkProfile is package-private, privately constructed and immutable. Its six package-private getters expose policy values only. A valid file is not a live app/native/source or security-authority grant.

The fixed path is /data/system/oneos_retained_root_link. Only ENOENT for this final file, after parent validation, returns null/disabled. All other failures propagate. The loader lstat-checks /, /data and /data/system as non-symlink directories, retains an opened read-only O_NOFOLLOW/O_CLOEXEC/O_NONBLOCK parent FD, and compares descriptor/path identities before and after reading. It invents no root ownership or mode requirement for /data/system. Literal components contain no dot segments; canonicality here means checked literal ancestors, not an unsupported Os.realpath API or an atomic directory lease.

The final file must be regular/non-symlink, UID0/GID1000, mode0440, link count1, size1..2048. O_NOFOLLOW/O_CLOEXEC/O_NONBLOCK opens the file; fstat identity, ownership/mode, size, modification/change times including nanoseconds, and final lstat/path and parent checks bind the read. Reads are bounded to stat size plus one byte and require exact size/EOF. Atime is excluded. This is before/after source admission, not protection against root compromise or an atomic live generation.

There are exactly seven ASCII key/value lines in any order: version=1, package, signer, apk, code, native and bytes. Unknown/duplicate/missing keys, whitespace/control/non-ASCII bytes, blank lines, additional '=' and CRLF are refused. LF-only input permits one final LF. Package is com.fahadali.oneos or a dot-suffixed development name with letter-led alphanumeric/underscore segments. Hashes require exactly64 lowercase hex characters. Code is a canonical positive decimal long; native bytes is1..2097152. Signed, leading-zero or overflowing decimals are refused. No file contents or errors are logged.

A private process-retained ReadAttempt is claimed before the first framework query. Every returned descriptor is stored immediately. Opening progress, actual descriptors, original failure and close progress remain retained even when loading fails; any later load refuses without querying or reopening. Each close-attempt bit is consumed before public Os.close; both cleanup attempts run and preserve the exact primary Throwable, guarding self-suppression/suppression failure. An uncertain close is never retried. A clean missing-file observation remains disabled; the one-shot module must not poll it into authority.

The first85bb implementation had only local FD references and could lose uncertain descriptor custody after unwinding. Root identified that defect before compilation. The finite original Samsung bind-source read has a useful precise result: AMS.checkComponentPermission compares the actual PID argument against AMS.MY_PID first and returns granted before permission/exported fallback. The existing ActiveServices bind chain obtains real Binder caller PID/UID and reaches this check. This supports a conditional genuine same-SystemServer request to an exported=false service, not permission for an arbitrary source asserting UID1000. The generic ActivityManager fallback invokes canAccessUnexportedComponents(uid), whose body was not selected. Other original resolution, user, package, process, firewall, background and callback gates remain; no successful bind or authority is inferred.

Root selected explicit user0 bindServiceAsUser using only Registry's actual captured SystemContext. The earlier UserHandle.of(0) public-API inference was rejected by the same SDK compile; the corrected user-handle derivation belongs to the binding author. That source integration is owned elsewhere; this profile accepts no Context or caller identity. The current API inventory and actual bind-path/source references are pinned in the inventory. Source/code/loader, app signer/APK/currentness, callback association and native/session lifetime remain separate admission work.
