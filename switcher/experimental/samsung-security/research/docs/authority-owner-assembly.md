# Authority owner assembly: cold construction decision

**Source-supported conditional sequence; no executable cold authority is closed.** The next missing engineering binding is the original persisted user-registry/UMI owner, admitted before its constructor reads state. More generic protocol leaves will not supply it. This report selects concrete owner candidates for comparison, not a runtime architecture or permission to construct them. All18 GOAL cases remain open. No source audit, code change, private-state read, OEM/native execution or phone action was added.

The finite source basis is [METHOD_REVIEW](../METHOD_REVIEW.md), [BOOTSTRAP](../BOOTSTRAP.md), the seven bootstrap cards, [local control](local-locksettings-contract.md), [policy ownership](security-policy-owner.md), [credential construction](construction-credentials.md), [quiescence](security-authority-quiescence.md) and the two retained-authority cards. The companion inventory pins these inputs. PCs below are decimal unless prefixed `0x`; they are method-relative code units, or explicitly OneOS source lines.

## Samsung objects versus guest read managers

Actual Samsung objects are required for Class-keyed UMI, DPMS DeviceStateCache and policy delegates, Supervision, concrete SLD/store, LSS/SPM/LocalService/StrongAuth/recoverable/RoR, and the same original biometric provider/scheduler family. A guest client manager may supply only a reviewed typed service operation from its real owner: display metadata, original caller permission query, AM unlock/progress or package/admin lookup cannot be generalized to all methods of those managers. The original Context/Resources/ConfigurationController/ResourcesManager and their updates remain Samsung objects. A snapshot RAW5 reply is input to one original metrics calculation, not a complete DisplayInfo, configuration stream or Resources update owner.

The new DMS8/9/12-unit payload is a reviewed **unselected fixed-OFF static prototype**; its forward/reemit/header/inverse proof does not produce an enabled source or live endpoint. The ParentClient remains a prepared transport with native-header/BOOT/current-parent admission outstanding. Neither artifact closes stages1–3. Actual original CompatSandbox, CompatibilityInfo and live configuration/selected display branches must remain; do not freeze boot metrics to evade later changes.

Native Binder UID preservation is necessary but insufficient. The original PM/AM must understand the guest caller's actual package, permission/AppOps, attribution, user/profile and component identity. OneOS's intended appid15000 mitigation is not proof of disjoint allocations; shared UID1000 and system key namespaces remain shared. Keystore APP isolation follows the actual caller UID; namespace103 is the original locksettings domain and100 the vold domain. Genuine app-key, HAT/challenge and CE ownership cannot be inferred from matching numeric user IDs, copied package tables or transport success. The prepared permission bridge preserves actual query subjects; original system-appId shortcuts and source-local cache currentness remain admission limitations, not caller attestation.

## Cold cost against retention's six gates

| Retention gate | Cold process still owes | What keeping the actual initialized owners could avoid |
| --- | --- | --- |
| Parent/zygote/watchdog | Old real drain, independent new process lifetime and no duplicate restart; original VM/native launch. | Reconstructing VM/Context/native registrations, but actual zygote/init/watchdog survival is unproved. |
| Whole-thread state/mount/property view | Original registry/policy/storage view before every constructor; legitimate live CE propagation. | Reload/recovery/migration merely to recreate owners; retained workers still need correct future paths/properties. |
| Endpoints/local/lifecycle | Both guarded protocols, complete aliases,18 local operations, original user/phase updates. | Recreating Samsung local Classes/objects; guest proxy/caller/control obligations remain. |

| Physical/native biometric | Original FP family, sensor/session/metadata and WM/display/input/power/UI owners before cleanup. | Provider reconstruction and repeated eager cleanup; physical exclusivity and genuine callbacks remain. |
| Return/drain | Retire new family plus native/persistence children before stock reconstructs. | Inter-writer transfer if genuinely resuming the same graph; all guest work still drains and current OneOS force-teardown must change coherently. |

**METHOD_REVIEW stop criterion:** the evidence does not prove that literally every Samsung SystemServer service is required. UMS's handler edge is narrowly replaceable, storage can use its genuine original endpoint without a new SMS, and the fingerprint family has a finite start order. Nevertheless, unmodified cold ownership already reaches real DPMS delegates and PM/AM/ATM/UMI inputs, Supervision role/DPM listeners, SLD's factor/controller graph, and biometric WM/statusbar/AM/native/UI owners. No closed extraction supplies their required state and updates. Calling this a small ready security process would hide a substantial reconstruction of framework authorities. Dedicated cold placement therefore has **not earned preference or a lower-cost claim**; if those real owners require a second broad server graph, its stated preference criterion fails. This report does not select retention or the guest-import fallback.

**One next engineering binding for root review:** original **UMS registry/UMI ownership**, before additional compatibility work. Specify the actual Samsung state view/sole-writer transfer; use the proved original UserManagerHandler factory in place of the null-PMS acquisition; retain original type defaults and file recovery/disposition; publish the actual same-realm UMI; and bind the genuine active guest UserController lifecycle/CE producer to that same user/serial/profile generation with initial-state ordering and drain. Original Samsung finishUserBoot75/setUserState and finishUserStopped194/removeUserState versus guest51/229 identify the real producer seam. This is one owner assembly with a precise earliest load boundary, not permission to expose UMS's unreviewed general Binder surface or claim a handler patch supplies authority. If root cannot supply that physical/current owner without a broad PMS/AM reconstruction, stop the cold branch at stage2 and evaluate retention against its six concrete gates before emitting further cold leaves.
