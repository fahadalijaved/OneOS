**Finite source contract; capture-only API approved in principle, unselected.** This component would retain the already-created original Samsung credential/biometric family inside the original system_server. It must not construct it, query authentication, realize a HAL/provider, publish a Binder, or grant readiness/authority. No Android/OEM code or phone operation ran. The source profile is literal Samsung services `def967fb…639f6` and framework `8095a9ae…71fe`, not the staged OneOS/ColorOS service profile.
