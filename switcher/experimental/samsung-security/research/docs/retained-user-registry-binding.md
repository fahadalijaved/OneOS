**Approved prospective capture-only component; unselected.** It can retain a consistent set of already-existing original Samsung owners inside their current process. It cannot initialize them, attest their code/process, establish a user/policy/native generation, isolate paths, or complete the guest lifecycle. No OEM constructor, service/native method or phone action was executed by this worker. Existing frozen reports and guards remain unchanged.

## Exact acquisition and placement

No API takes an owner object, Binder, UID, source hash, readiness Boolean or authority callback. A private result retains the actual objects and cached exact reflection metadata. No public getter grants access to the underlying services. Missing/inconsistent state throws; it never supplies a replacement or rebinds.

The caller must already be inside the admitted original Samsung system_server before OneOS stop971. This is an explicit source/placement precondition, not something Java names or the capture object can attest. The source-backed deterministic selector is:

`Class.forName(false)` does not promise universal absence of class initialization: a misplaced early call could initialize the LocalServices utility class before refusing empty roots.
