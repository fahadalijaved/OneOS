# Guest metrics producer: authored-only build gate

**Root approved the RAW producer API and the exact production source is frozen.** The build uses only PreparedGuestMetricsProducer SHA256 `72b0f4cdbb984c4d3b59724fd4c671771f8bf7e81c48184351e9ce77aa27b8f7`; actual compile/D8 status and hashes are in the inventory. No source glob, OEM fixture, old build rerun or Android execution is part of this gate. The [display contract](context-display-contract.md) remains the source boundary: genuine one-result guest DisplayInfo projection, coherent five-field raw metrics, and retained original Samsung configuration/compatibility calculation are unassembled runtime obligations.

Power owns the proposed PreparedGuestMetricsProducer source; root owns API approval and selection. The approved `prepare(retainedRealColorOsDmsBinderService)` / `capture(displayId)` API returns only an immutable five-value RAW Sample or genuine absence; it supplies no source, endpoint, generation or Context admission. This builder will not discover a moving class or infer dependencies from the existing root PreparedSamsungDisplayBridge. That bridge supports only two separate display metadata transactions and does not solve DisplayInfo conversion or metrics provenance.

## Explicit build order

1. Root approves exact producer signatures, coherence/ownership and exposed result/refusal behavior. Power sends final production paths, source SHA256 values, dependencies and exact binary names, including nested classes. Only then create an explicit reviewed manifest in ignored `out/guest-metrics-producer-build/`.
2. Pin those direct authored sources and frozen source-evidence documents/inventories. No moving module output/build receipt is an immutable producer input. `--check-manifest` verifies the explicit set without compilation.
3. Compile that set once using the existing JDK, local TMP/TEMP and JVM temp/home under an exclusive run directory, `-proc:none -implicit:none -source 8 -target 8 -sourcepath ''`, and the actual pinned SDK37 android.jar. Hidden/OEM API dependencies must use the reviewed source API; no invented compiler stubs or automatic source discovery.
4. D8 only the emitted authored class files with SDK37 as `--lib`; compare the exact class and DEX definition sets against the reviewed manifest. Reject foreign, missing, duplicate, SDK, test or compiler-only definitions. Emit a DEX-only authored jar and immutable run receipt. Record all real compiler/D8 warnings, including the known requested API37/maximum36 warning if emitted.
5. Recheck complete source/evidence/manifest/helper/JDK/SDK/D8 pins before publishing the result. A moved source invalidates the checkpoint; do not relabel a prior receipt or restart while an owner is editing.

## CLI and manifest contract

`python -B tools/build_guest_metrics_producer.py --prepare` writes only the prepared metadata and fixed tool cache, no source manifest or subprocess build. The cache pins current javac/java, the existing bounded runner/parser helper, SDK37 `bf1b4387…` and D8 `a26ee562…`. Literal SDK/D8 mismatches raise an explicit exception even with Python optimization enabled. Drift requires review, not automatic cache refresh.

After coordination, use `--manifest out/guest-metrics-producer-build/<reviewed-name>.json --check-manifest`, then the same `--manifest` without the check flag for the single final build. Manifest schema `guest-metrics-sources/v1` requires exactly: `schema`, `frozen:true`, a bounded `apiReview` reference, `sources:[{path,sha256}]`, exact slash-form `definitions:[...]` and `sourceEvidence:[{path,sha256}]`. Sources must be explicit authored authority Android Java files; evidence must be frozen authored docs/inventory, not a moving build receipt. The review reference records a prior human/root decision; its text is not runtime authentication. The explicit frozen manifest pins only the production source plus the producer source-proof documents/inventory. No fixture source or moving generated receipt is a production input. Java8 may emit the exact third `PreparedGuestMetricsProducer$1` access-marker definition for the private Sample constructor: only that named class is allowed, and only after class52/ACC_SUPER|ACC_SYNTHETIC/Object/zero-interface/zero-field/zero-method inspection and actual javap proof of the synthetic Sample constructor and original caller reference. No arbitrary extra definitions or Java17 switch are accepted.

## Honest isolation and acceptance boundary

The gate checks **emitted-definition isolation**: only the reviewed authored class definitions reach the DEX, leaving framework references external. It does not execute Android/OEM classes on PC, import SDK stubs for a green loader fixture, or establish ART class-loader behavior, canonical class identity, real endpoint provenance or Binder caller identity. Runtime loader/source/owner admission remains root-owned. Compiler output does not prove genuine raw metrics, current DMS state, generation/coherence, callback/cache lifetime, original config/compat application, safe Context retarget, resource/native behavior or Android readiness.

Source8/target8 emits class52 but is not a Java8 release API check. D8 output is an artifact, not API37 runtime support. There is no phone push/launch/install, cache installation, endpoint publication, OEM fixture, policy/security operation or authority-ready claim. [The inventory](../inventory/guest-metrics-producer-build.json) distinguishes PREPARED_NOT_COMPILED from the actual approved frozen SDK37/D8 result. Independent authored-only fixtures may later execute these exact compiled class bytes in their separate owner scope; this builder does not execute them or merge their result into Android evidence.
