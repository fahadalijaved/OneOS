# Preparation-only Stop status fixture

The held Full app uses **Stop setup** and **Keep going** in `SetupProgressActivity`. Its legacy `PrepareJob.cancel()` addresses a different job. The saved private-view module has package-private request, close and observation methods, and the native client has an internal local cleanup predicate. The held app has no preparation result or cancellation type backed by those methods. [UI source trace](../../../out/oneos-preparation-ui-contract/TRACE.md)

`ViewPreparationStatus` is a main-owner projection. Retain one instance with the already-recorded `ViewPreparationOccurrence` across screen recreation. A Stop dialog has its own identity. Keep going, Back or dismissal clears that dialog only. Confirming Stop invalidates the dialog, disables repeated Stop and returns the same occurrence once so a future caller can request close. Closing or recreating the screen can read the same snapshot and leaves the operation alone.

The projection takes separate preparation and close observations from the exact occurrence. A partial observation leaves Stop available, and an arriving partial result cannot clear **Stopping**. Stage-needed and refusal messages remain visible while cleanup settles. A local terminal observation remains pending until a separate cleanup result. **Cancelled** requires an explicit source-confirmed Stop, such as confirmed no dispatch or confirmed same-attempt cancellation after cleanup. Generic local cleanup confirmation is a separate result. Unavailable and unconfirmed results stay sticky for this occurrence. The fixture does not assign numeric wire states to its categories. A future producer must derive them from the same owner and provide a definitive cleanup disposition.

Eleven inert JVM cases passed with Kotlin 2.1.21 and the existing JBR. The fixture uses the unchanged `ViewPreparationOccurrence` and held `LaunchCommitGuard` source. Its close sink is an in-memory list. Exact source snapshots, tool pins, commands, output and generated class hashes are saved in the run receipt.
